## 📖 About

**StartHubX** is a platform that connects founders, developers, designers, and creators to turn ideas into real products. It lets founders post their startups and open roles, and lets collaborators discover opportunities, apply, and join teams — helping people find the right team, collaborate seamlessly, and bring startups to life faster.

## ✨ Features

- **Discover Startups** — Browse featured and all listed startups across industries like EdTech, FinTech, AgriTech, Gaming, and more.
- **Opportunities Board** — Explore open roles filtered by type (remote, onsite, hybrid) and commitment (full-time, part-time).
- **Founder Dashboard** — A dedicated space for founders to manage their startup listings and openings.
- **Verified Profiles** — Collaborators are verified with portfolio links and skill endorsements.
- **Global Reach** — Connect with talent from 80+ countries.
- **Fast Matching** — Post opportunities and start receiving applications within hours.
- **Admin Dashboard** — A dedicated admin panel with real-time metrics: gross earnings, total revenue, registered startups, active opportunity roles, and total platform users, plus tools to manage users, manage startups, and view transactions.
- **Authentication** — Secure sign-in/sign-up and session management powered by Better Auth.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/start-hub-x-client.git
cd start-hub-x-client

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Environment Variables

Create a `.env.local` file in the project root and add any required keys, for example:

```env
NEXT_PUBLIC_API_URL=your_api_url_here
```
